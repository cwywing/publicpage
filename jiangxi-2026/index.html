景点解说

  1. ▸山名从三清来

    三清山在上饶玉山。玉京、玉虚、玉华三峰并立，后人比作道教里的玉清、上清、太清，山名由此来。地方志记南宋乾道六年（1170）王霖建三清观，明代景泰年间重修为三清宫。葛洪或葛玄在此炼丹，两说都有，属于开山传说。

  2. ▸花岗岩峰林怎么来的

    山体主岩是白垩纪花岗岩，大约一亿两千万年前岩浆侵入，后来被抬出地面。岩体里有近于直立的节理，水沿缝往下切，软的先掉，硬的留成石柱和峰林。南清园那片不是人工堆的，是风化剥蚀剩下的。主峰玉京峰海拔一千八百一十七米。

  3. ▸巨蟒和女神是风化

    巨蟒出山是一根顺着节理留下的花岗岩石柱，远看像蛇抬头，名字是后人起的。东方女神是侧面一块像人脸的岩石，同样是风化造型，不是雕刻。世界遗产的记录也把它们算作石柱。山上没有真蟒，也没有一尊神。

  4. ▸南清园与三清宫

    南清园是石柱最密的一片，巨蟒、女神都在附近，石峰的名字多半按形状附会。道教宫观集中在三清宫一带，跟南清园的自然造型不是一回事。看石头，在南清园；看香火和明代的宫，得到三清宫。两边可以同一天走。

  5. ▸世界遗产和后来的栈道

    2008年，三清山因花岗岩峰林和生物多样性列入世界自然遗产，评的是山，不是庙。1988年它已是国家级风景名胜区。现在的索道和西海岸栈道，是近几十年为旅游修的。古代上山靠石阶。路是新的，山老得多。

  1. ▸谷名是乡里传说

    望仙谷在上饶广信，灵山北麓。乡名「望仙」有一套本地传说：三国隐士胡昭在山里修炼，家人筑台远望，后来叫望仙台。正史里的胡昭隐居在河南，没有南下江西的记载。这故事当乡里传说听，谷名是跟着乡名走的。

  2. ▸花岗岩峡谷怎么切出来

    这是一条花岗岩峡谷。溪水长期下切，切出陡壁、瀑布和河床上的壶穴。白鹤崖是一面一百多米高的石壁。白鹤衔果救村民，是洪水传说，没有史料。山石曾被采去作板材，2007年停采，峡谷才慢慢恢复。

  3. ▸崖上的房子是新盖的

    崖上那些房子，是停采以后仿赣东北民居新盖的，不是古代崖居。老村里有少量旧屋被修回来，更多是仿建。景区2020年10月开园。胡氏宗祠、杨府这类，是用本地名人做的新布景，别看成明清原物。

    瀑布是溪水从花岗岩陡坎上跌下来的，白天看水和石壁就够。岩壁上的垂直节理，把山切成一块块峭壁，房子才挂得上去。三叠水和壶穴都是流水冲出来的，不是人工水景。彩灯是后来加的。水大才有气势，旱季会细。

景点解说

  1. ▸县志里的篁岭

    篁岭在婺源东北的山坡上。清道光《婺源县志》说此地古名篁里，多竹，所以叫篁岭，曹氏世居。房子是白墙黛瓦的徽派民居，从水口往上呈扇形叠在坡上。现存多为明清砖木老屋。它是山里的村子，不是河边的商埠。

  2. ▸晒秋本来是农活

    坡陡，平地少，辣椒、玉米、皇菊摊不开，就用竹匾放在屋顶晒架上，这叫晒秋，本来是农活。近些年景区会把匾摆整齐，方便拍照，所以你看到的有传统，也有布置。十月正值晒季，叶子未必已经全红。

  3. ▸村名和曹氏迁徙

    「篁」就是竹，村名跟竹林有关，这是县志的解释。建村时间，族谱多记在明宣德年间，说曹氏从徽州歙县一带迁来。更早还有唐末避乱、先到歙县的说法。这些是谱牒，不是正史定论，当家族迁徙传说听。

  4. ▸房子为什么叠在坡上

    房子贴着山坡建，前低后高，屋顶连成梯。晒架是为了在陡地上腾出一块平面，不是装饰。巷子窄、台阶多，是地形逼出来的。水口林在村子下方，是徽州村子常见的入口。从对面看整片屋顶，比钻进巷子更像它的格局。

  5. ▸跟河谷村子不一样

    李坑、汪口、江湾多在河谷，出名的是水巷、宗祠和徽商宅子。篁岭在山上，出名的是屋顶晒秋和坡地梯田。都在徽州文化圈里，过日子的场景不一样。十月这里是秋收，不是三四月的油菜花。别拿河边古村的标准来套它。

景点解说

  1. ▸镇名从景德年来

    景德镇旧称昌南。北宋景德年间，宫廷用瓷底部署「景德年制」，镇名由此来，年份是公元1004到1007年。它能成瓷都，是因为附近有瓷石、高岭土、松柴和水。外销瓷后来大量从这里出去。镇名是年号，不是窑神赐的。

    这段音频没加载出来，先看文字。

  2. ▸高岭土和制瓷

    高岭土因浮梁高岭村得名，是花岗岩风化后的黏土。欧洲语言里这类白土的名字，就是从「高岭」音译过去的。制瓷用瓷石配高岭土，拉坯、上釉、进窑。温度和气氛一变，釉色就不同。博物馆按朝代排的，是这条工艺史。

  3. ▸御窑和砸碎的次品

    元代至元十五年（1278）在珠山设浮梁瓷局，给宫廷造瓷。明洪武二年（1369）改成御器厂，清代叫御窑厂，一直办到清末。贡品进宫，砸碎的次品就地埋掉，这是考古挖出来的，不是传说。御窑博物馆看的就是这些窑和残片。

  4. ▸民窑和陶溪川

    御窑之外，民窑烧日用瓷和外销瓷，数量大得多。二十世纪，市区建成一批国营瓷厂，宇宙瓷厂是其中一座。厂停以后，锯齿厂房和烟囱留着，改成陶溪川。那是近代工业遗产，不是明清的窑。夜景归夜景，别把它当成御窑。

  5. ▸三宝是当代陶艺村

    三宝村原来就有做瓷的作坊。1995年，陶艺家李见深在这里办三宝陶艺研修院，各地做陶的人把工作室设进来，慢慢变成三宝国际陶艺村。看的是还在用的拉坯和窑。跟御窑的区别：一个是当代创作的村子，一个是明清宫廷窑址。

景点解说

  1. ▸断块山，不是冰川定论

    庐山是断块山。两侧断层把山体抬起来，旁边陷下去的是鄱阳湖平原，所以山坡陡，平地会突然接上高峰。李四光曾用某些地貌论证第四纪冰川，这个说法争议很大，不能当成定论。能确定的是断层抬升，不是冰川导游词。

    这段音频没加载出来，先看文字。

  2. ▸不识庐山真面目

    「不识庐山真面目，只缘身在此山中」出自苏轼《题西林壁》，写在宋代，地点在西林寺一带。他写的是人在山里，被山脊和云挡住，换一个位置就看成另一座山。庐山的名气，很大一块来自这类诗文，不是来自某一块奇石。

  3. ▸牯岭别墅从租地来

    清末，英国传教士李德立租下长冲一带，改名牯岭，划地卖给外国人盖避暑别墅。房子是购地人自建的，风格不统一。美庐是后来蒋介石、宋美龄住过的一栋。牯岭这些石头别墅，是这百来年的避暑史，不是古代庙宇。

  4. ▸东林寺老，大佛新

    东林寺在庐山西北麓。东晋太元九年（384）起，江州刺史桓伊为慧远建寺，慧远在此倡念佛，后来被看成净土宗祖庭。白莲社是同期的结社说法。温泉镇那尊约四十八米的东林大佛，2012年前后才完工，是新铸铜像，不是寺里的古佛。

    花径纪念白居易。他贬到江州后，在庐山写过「人间四月芳菲尽，山寺桃花始盛开」，说的是大林寺。仙人洞是悬崖上的天然石洞，道教曾在这里活动；洞外石缝里的松，后来因一张照片被认出来。锦绣谷的名字来自花草。含鄱口对着鄱阳湖口。
